## 10/18/2025 - Researched literally everything about the project  

Today I'm starting my Blueprint project! I want to build a voice assistant 
that runs 100% locally - no Google, Amazon, or any company getting my voice 
data. I've been researching how commercial voice assistants work and why 
privacy matters for IoT devices.

RESEARCH FINDINGS:

Voice Assistant Components:
- Microphone array for far-field voice pickup (at least 3-4 mics needed)
- Main computer for processing (Raspberry Pi 5 seems powerful enough)
- AI models for speech-to-text (discovered Whisper from OpenAI)
- Text-to-speech for responses (found Piper for local TTS)
- Speaker system for audio output
- LED indicators for status

Privacy Concerns I Found:
- Google Nest/Alexa send all voice to cloud servers
- Companies store voice recordings indefinitely
- Voice data used to train AI models
- Third parties can access data
- Can't work without internet

Local Processing Benefits:
- Complete privacy - voice never leaves home
- Works offline (no internet needed)
- Faster response (no cloud latency)
- You own your data
- Learning opportunity about AI/embedded systems

HARDWARE RESEARCH:

Microphone Arrays:
- Discovered ReSpeaker Mic Array v2.0 ($50)
  * Has 4 PDM microphones
  * 12 RGB LEDs built-in (status indicators!)
  * 5m far-field voice detection
  * USB plug-and-play with Raspberry Pi
  * Has audio processing algorithms (AEC, noise suppression)

Computing Options:
- Raspberry Pi 5 4GB ($60) vs 8GB ($80)
  * 4GB should be enough for Home Assistant + Whisper AI
  * 2.4 GHz quad-core processor
  * Has USB ports for ReSpeaker connection
  * M.2 slot for AI accelerator
- Raspberry Pi AI Kit ($70) - Hailo-8L chip
  * Speeds up local AI processing 2-3x
  * Makes voice response feel instant (1-2 seconds)
  * Without it, voice processing is 4-6 seconds (too slow)

SOFTWARE RESEARCH:

Home Assistant:
- Open source smart home platform
- Free forever (no subscriptions)
- Has built-in local voice processing
- Supports Whisper for speech-to-text
- Supports Piper for text-to-speech
- Can control smart home devices
